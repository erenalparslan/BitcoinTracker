# Bitcoin Tracker
<div align="center"><h2>Bitcoin Tracker</h2> </div>


 <p>
Easily track cryptocurrencies with Bitcoin Tracker!

Check real-time prices and changes.
Get detailed information about each cryptocurrency.
Add your favorites for quick access.
 </p>

## Features
  <List>
        <li>Coin Search</li>
        <li>My coins page</li>
        <li>Realtime coin price tracking</li>
        <li>Firebase Authentication</li>
      </List>
      

## Technologies

- [Navigation Component](https://developer.android.com/guide/navigation)
- [MVVM (Model-View-ViewModel)](https://developer.android.com/jetpack/docs/guide#recommended-app-arch)
- [Hilt](https://developer.android.com/training/dependency-injection/hilt-android)
- [Coil](https://github.com/coil-kt/coil)
- [Coroutine](https://developer.android.com/kotlin/coroutines)
- [Flows](https://developer.android.com/kotlin/flow)
- [Retrofit](https://square.github.io/retrofit/)
